# Third-party software

The simulator itself, its artwork, mission patches and emblem are original. Shipped third-party components:

| Component | Licence | Used for |
|---|---|---|
| three.js | MIT | 3D scenes (assembly editor, launch pad, orbits) |
| React, React DOM | MIT | user interface |
| @fontsource/ibm-plex-sans, ibm-plex-mono | SIL Open Font Licence 1.1 | "Houston graphite" theme |
| @fontsource/barlow-semi-condensed | SIL OFL 1.1 | "Houston graphite" headings |
| @fontsource/source-serif-4, source-sans-3, source-code-pro | SIL OFL 1.1 | "Blueprint paper" theme |
| @fontsource/bebas-neue, work-sans, courier-prime | SIL OFL 1.1 | "Apollo era" theme |

Build tools (Vite, TypeScript, Vitest, tsx, vite-plugin-singlefile) are development dependencies and are not shipped.
Space agencies, missions and launch vehicles are named only to state public facts on the "Real data" page and in technology-tree
notes; this project is not affiliated with, endorsed by or a product of any agency or company.
